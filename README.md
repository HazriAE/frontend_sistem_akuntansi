# Sistem Akuntansi

Proyek ini adalah aplikasi **Sistem Akuntansi** berbasis **React + Vite** yang menggunakan beberapa library pendukung seperti TailwindCSS, DaisyUI, React Query, Formik, dan lainnya.

Pastikan mengikuti langkah-langkah di bawah sebelum menjalankan proyek ini.

---

## Persyaratan

Sebelum memulai, pastikan Anda sudah menginstal:

- **Node.js** (versi terbaru direkomendasikan)  
  Cek versi dengan perintah:
  ```bash
  node -v

## Cara instalasi

- clone repository
  ```bash
  git clone <link repo ini>

- Masuk ke folder proyek
  ```bash
  cd nama-folder-proyek

- Install seluruh dependencies
  ```bash
  npm install

- Menjalankan Proyek
  ```bash
  npm run dev
